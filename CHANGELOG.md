# Changelog

Notable changes to the Open Sonara website. This is the website's own history; Sonara's application changelog lives in the [core repository](https://github.com/Open-Sonara/Sonara/blob/main/CHANGELOG.md).

## Unreleased

### Added

- Website Phase 1: brand system, homepage, features directory, about page, navigation with a mobile drawer, GitHub integration with a cached fallback, SEO metadata, sitemap, robots and Open Graph image.
- Central configuration for site identity, navigation and page flags, release status, features, platforms, integrations, ecosystem and community links.
- Standalone and static-export builds, a non-root Docker image, Docker Compose example, CI (typecheck, lint, unit, end-to-end, accessibility, broken links, Docker) and an image publishing workflow.
